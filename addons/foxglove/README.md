# Foxglove add-on

`rosdev addon add foxglove` installs `foxglove_bridge` into your image (local/Dockerfile)
and starts it with the container on `ws://localhost:8765`.

Open the Foxglove app (https://app.foxglove.dev or the desktop app), choose
"Open connection" → "Foxglove WebSocket" → `ws://localhost:8765`.
